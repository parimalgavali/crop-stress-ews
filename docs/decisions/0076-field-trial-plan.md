# ADR 0076: Field-trial preparation without claiming validation

- Status: accepted as a plan, 2026-11-26
- Context: #171 needs a way to assess whether warnings help actual field visits. ADR 0060
  already supplies device-local visit records and JSON export, not central collection.
- Decision: docs/field_trial.md describes opt-in recruitment, adviser review, predeclared visit
  budgets and comparison sampling, exports, uncertainty and useful findings per inspection
  hour. Original canopy scoring stays separate from observed symptoms. Consent, recruitment,
  actual visits and confirmation are future work with human partners, not completed results.
