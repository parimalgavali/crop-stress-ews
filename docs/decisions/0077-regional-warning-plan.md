# ADR 0077: Regional warnings require a separate experiment

- Status: accepted as a plan, 2026-11-26
- Context: #172 addresses district-wide problems invisible to peer-relative field labels.
- Decision: docs/regional_warning_experiment.md requires independent dated outcomes, simple
  baselines, issue-date data availability, season-based splits, uncertainty at regional units,
  and prospective confirmation against predeclared practical gates. No regional model is
  implemented and current field predictions are unchanged. Without independent outcomes,
  retain descriptive context rather than claim a new risk forecast.
