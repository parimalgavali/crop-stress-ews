# 0003 — Code licence: MIT

Status: Accepted (2026-10-26)

## Context

The repository is public and serves as a portfolio project. Without a licence, others have no
right to reuse the code.

## Decision

- The code in this repository is licensed under MIT (`LICENSE`, `license = { text = "MIT" }` in
  `pyproject.toml`).
- The licence covers only the code. Datasets (Europe-LAND IACS, Sentinel-2, BKG, DWD, IT.NRW) are
  not committed or redistributed and keep their own licences — see
  [0002](0002-data-sources.md).
