# ADR 0074: Plain-language field-warning guidance

- Status: accepted, 2026-11-26
- Context: people need to know what a warning predicts and how to follow it up (#168).
- Decision: English/German alerts describe falling behind nearby wheat fields, recommend a
  field inspection, and explicitly leave the cause unknown. No treatment recommendation.
  Existing thresholds, episode cooldown, authentication and delivery stay unchanged.
